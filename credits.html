FB Unlocker Pro v2.2.0

Instant uncropped cover photo & profile picture previewer with one-key full-resolution saving.

How It Works

When a Facebook profile is locked, Facebook places a transparent interaction overlay (aria-label="Learn more") over the cover photo and profile picture to block clicks. FB Unlocker Pro bypasses that click-shield locally inside your browser DOM, reads the underlying media asset, and renders an uncropped floating preview card on hover.

Core Capabilities

Locked & Unlocked Covers

Detects both standard cover links and locked-profile banner overlays without relying on fragile CSS classes.

SVG Avatar Extraction

Parses Facebook's SVG profile picture containers to preview full-frame avatars on hover.

Highest-Res Selector

Automatically evaluates srcset candidates to extract the largest available CDN resolution.

Instant Hotkey Saver

Press D or Ctrl+S while hovering to download directly via the background service worker.

Privacy & Security Guarantee

  • 100% Local Execution: No external servers, analytics, or tracking scripts are used.
  • Zero Account Risk: Operates purely on already-rendered DOM elements without making automated API requests.
  • Minimal Permissions: Only uses downloads (to save images when you press the hotkey) and storage (to remember your on/off toggle).
